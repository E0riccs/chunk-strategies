# 直接评价
直接对分割好的文本进行评价。

## 1. 量化评价
1. 语义抽取：使用 llm 总结语义；
2. 令牌化：分词，生成抽取语义与chunk的令牌；
3. 令牌评价：计算相关指标
缺陷：无法对应主观感受

## 2. 相似度评价
1. reranker模型，观察 top-k 的文本与原始文本的相似度；

## 3. 大模型评价
1. 直接使用大模型对分片结果进行评价；
    1. 总结原文本；
    2. 逐一阅读分片结果，判断该分片能够帮助解决潜在问题的能力
缺陷：大模型上下文有限

# 使用评价
利用分割好后的文本，进行实际的问答操作，对回答结果进行评价。
## 大模型评价
1. 使用大模型（large）对原文生成QA对；
2. 使用大模型（small）对分片结果，进行reranker后，回答Qs；
3. 计算QA对的召回率；/ 使用大模型（large）比较Q-A-A，给出主观评分；
